## 1. 开场公式（第一句 ≤ 20 字，必须带称呼或动作）

| 公式 | 例句（结构，不是让你抄） |
|---|---|
| 称呼 + 变化 | 宝子们，Muse 这周大批账号被封 |
| 直接动作 | 没账号的先别急，三步就能开通 |
| 反常识 | 30 刀能同时用三个会员，你信不信 |
| 承诺 + 时间 | 今天十分钟，把这件事讲透 |

**禁止**用这类开场：「这波封号已经不是新闻，是身边事」——抽象、书面、没有动作。

## 2. 语言硬指标（可以机械检查）

| 指标 | 标准 |
|---|---|
| 小句长度 | 平均 8–15 字；超过 25 字的小句占比 <10% |
| 标点节奏 | 每 2–4 个小句一个逗号；每 30–60 字必须出现一个数字 |
| 数字密度 | 整篇 ≥6 个具体数字（价格/倍数/时间/版本/条目数） |
| 书面词 | 禁止：进行、实施、导致、目前、综上、值得注意、具备、方面、相关 |
| 抽象名词 | 每 5 句内至少 1 个具体产品名/动作动词（充、开通、退款、验证、复制、粘贴、刷新） |
| 人称 | 「你 / 大家 / 宝宝们 / 小伙伴」；不讲「用户」「读者」 |
| 括号补充 | 主语后面立刻跟功能补充：「X 负责聊天、语音、画图和做视频」 |

## 3. 档位 / 步骤写法（填空模板）

**档位**：每档三件套，缺一不可
```
<档位名> 每月 <价格>，额度是 <基准档> 的 <倍数>，<权益一句话>，适合 <哪类人>。
```
「适合哪类人」是这个号的关键手法——把选择权交给观众，也显得真懂。

**步骤**：一条一步，一步一个动作 + 一个画面
```
首先我们打开 <页面>，点击 <位置>；
然后 <动作>；
这里需要注意 <坑>；
最后 <结果>，回到 <页面> 刷新就能看到。
```

**遇到问题**（教程型必备）：
```
这里有的小伙伴会遇到 <现象>，这时先检查 <排查项>；
如果是 <原因>，就 <解法>。
```

## 4. 数字怎么用（本号最吃这套）

- 价格、倍数、折扣、时长、条目数一律给具体值：`30 刀`、`5 折`、`15 倍`、`两分钟`
- 先算旧账再算新账：`以前加起来一个月 90 刀，现在 30 刀全包`
- 数字后立刻给感受：`相当于花一份的钱拿三份会员`
- 优惠要有条件：`第一个月只要 15 刀，第二个月起才付原价`

## 5. 导流怎么写（本号手法，别改成喊广告）

**把购买动作写成教程步骤**：
```
进入 <平台> → 找到 <套餐> → 商家自动发货给你一个 CDK 卡密和自助充值网址
→ 打开充值网址 → 复制 CDK → 填 UID → 提交 → 等发货 → 刷新账号
```
口播里不出现价格、不喊「赶紧下单」，视频内零导流，转化靠评论区与账号主页。
需要放链接时用「下面我把链接放在置顶评论」这类说法。

## 6. 收尾模板

- 拆解型：`相信看到这儿，<选择> 你心里已经有答案了没有` → 降门槛一句 → `下面我带大家完整走一遍流程`
- 教程型：`以上仅为我的个人观点，也欢迎各位小伙伴分享你不同的看法`
- 互动：`感谢大家的观看，请不吝点赞、订阅、转发、打赏`

## 7. 反面清单（我们上一版就栽在这）

| 我们写坏的 | 引流号写法 |
|---|---|
| Muse 这波封号，已经不是新闻，是身边事 | 宝子们，Muse 这周大批账号被封了 |
| 但官方风控一收紧，弹人脸、断连接，大批账号直接封 | 风控收紧之后，先弹人脸，再断连接，最后直接封 |
| 中招原因很集中：多人共享、多地乱跳、脏节点登录 | 中招的 基本都是同一个号好几个人用，还到处换地方登录 |
| 想稳稳用住，记住四个固定：一人一号、设备固定、网络干净、正规使用 | 一人一个号、设备别换来换去、网络别乱跳、付款走官方渠道 |
| 在货源网的 Muse 专区里，各档套餐都有售后保障 | 套餐在下面那张图里，点进去能自己选档位 |

共同点：**具体的人话 + 具体的数字 + 具体的动作**，没有抽象概括。

## 8. 篇幅与分章：内容决定，不要预设

**没有固定时长**。母版 A/B 的骨架走完，信息讲完就收：

- 素材少 → 一章打完，可能就一两分钟
- 素材多 → 自然分章，一章讲透一件事
- 不为凑时长注水（重复总结、铺背景），也不为压时长删信息（数据、案例、例外条件）

分章只是把骨架按话题切开，常见切法（不是硬性规定）：

```
变化是什么 → 每一档细讲 → 常见问题与解法 → 开通流程 → 收尾与互动
```

每章内部仍然是「短句 + 数字 + 一个动作」，章节之间用一句过渡
（「先说结论」「接下来说说怎么用」「下面带大家走一遍流程」）。
章节表按 wvp `OUTLINE-FORMAT.md` 写进 `outline.md`。
