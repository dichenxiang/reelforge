# 写稿执行卡

## 唯一权威：wvp 的 SCRIPT-STYLE.md

口播怎么写，**以这个文件为准，我们不改它、不另立一套**：

```
<reelforge>/vendor/web-video-presentation/references/SCRIPT-STYLE.md
```

它包含（照着做，别复述、别改写、别自己另立）：

- 三条底线：信息保留度 ≥60% / 去 AI 味 / 保持原文语言
- B 站风格 8 条原则（形式层）
- 去 AI 味五类腔调（风骨层）
- 平台风格变体、主题类型微调
- **三层自检**：形式层 → 风骨层 → **念出来测试**（终极标准）
- Phase 1 的产出格式：落盘、切节拍、同时产出 `outline.md`

配套格式规范（outline 怎么写）：

```
<reelforge>/vendor/web-video-presentation/references/OUTLINE-FORMAT.md
```

**必读顺序**：SCRIPT-STYLE.md（全文）→ OUTLINE-FORMAT.md → 本文件。
任务包里会给出这两个文件的绝对路径。

## 本项目额外加的 4 条（只加这些，别的不加）

1. **画幅 16:9 / 1920×1080**（wvp 硬约束）
2. **单屏 ≤14 个汉字**：一屏一行大字，读不完就拆成两个 step
3. **账号人设与禁词**：任务包里已贴，照那个口吻写，禁词一个不许出现
4. **参考度**：默认 40、上限 60（`similarity.py` 会验）

这 4 条之外，风格、节奏、句式、留白、要不要用第一人称——**全部听 wvp 的**。

## 交付顺序（照 wvp Phase 1）

```
1. 检索取证 → source_digest.md
2. 写 script.md（--- 切节拍）
3. 三层自检：形式 → 风骨 → 念出来     ← 不许跳
4. 按 fail 项改稿
5. 产出 outline.md（按 OUTLINE-FORMAT.md）
6. 写 script.json + writer-notes.md
```

## 三层自检怎么执行

wvp 原文给的优先级是：**Agent Teams reviewer → subAgent → 自己逐项核查**。
有 Teams 就开一个 reviewer agent 把 `script.md` 和三层清单丢给它；
没有就自己严格逐项过，**「念出来」那条一定要按字面执行**（念不顺就改）。

拿到结论先改稿，再产出 outline。不许写完直接往下走。

## 常见的「不像人说话」（wvp 已经写了，这里只做提醒）

| 症状 | wvp 对应条款 |
|---|---|
| 新闻腔、书面语（「送百亿额度」「中招原因很集中」） | 原则 1 口语化 |
| 一句塞太多信息 | 原则 2 短句（≤20 字） |
| 第三人称讲读者 | 原则 3 第二人称 |
| 开头先铺垫 | 原则 4 钩子 |
| 没有停顿、连成一段 | 原则 5 用 `---` 分节拍 |
| 堆「首先/其次/值得注意」 | 原则 7 不堆结构词 |
| 只有结论没有例子 | 原则 8 具体例子优先 |
| 念出来像播报 | 风骨层五类 + 念出来测试 |
