# 长期测评号文案套路（阿测）

与引流号共用同一套**语言硬指标**（见 `patterns-gatekeeper.md` 第 2 节）：
短句、数字密度、禁书面词、第二人称、具体动作。

区别在**骨架与口气**：引流号是「替你选 / 带你开通」，长期号是「我测过了 / 我先给结论」。

## 骨架

```
① 先给结论      这东西值不值，我先说结论：值，但只对一半人
② 我的实测      我拿三个场景跑了一遍，结果分别是……
③ 差距在哪      好在哪、坑在哪，一次说清
④ 对谁合适      什么人用得值，什么人别碰
⑤ 收尾         一句话总结 + 互动
```

## 语气

- 第一人称：「我测」「我花了一晚上」「我跑了三遍」
- 敢下判断：`值` / `不值` / `只对一半人` / `我劝你别买`
- 数据先行：跑分、额度、耗时、失败次数，都给具体值
- 敢说坑：限制条件、例外情况必须讲（这是 wvp 的信息保留 ≥60% 也是这条）

## 反面

- 不许「综上所述」「综合来看」
- 不许「总体而言」「值得注意的是」
- 不许只夸不坑，也不许只踩不夸
- 不许把「我朋友说」当证据

## 与引流号的区别（别写混了）

| | 引流号（把关学长） | 长期号（阿测） |
|---|---|---|
| 落点 | 帮你开通 / 帮你选档 | 我测了，值不值在这 |
| 视角 | 教程视角，步骤多 | 实测视角，结论多 |
| 结尾 | 反问收束 + 求互动 | 一句话总结 + 互动 |
| 导流 | 购买写成教程步骤 | 不导流，靠内容本身 |
